# Meshy image-to-3D originals

Rigged, animated GLB characters generated by the project owner with Meshy (meshy.ai, free plan,
Meshy 7.1, Mixamo skeleton) from the A-pose references in `art-src/for-3d/`. These are the
untouched downloads; optimised runtime copies live under `apps/client/public/models/`.

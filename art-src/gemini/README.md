# Owner-supplied Gemini source art

Generated by the project owner with Google Gemini on 2026-10-25 from prompts written for this
project, with the owner's own reference paintings (`PHOTO-2026-10-24-*.jpg`) as style input.
These are the untouched originals (WebP, as received). Processed game assets derived from them
(sky panorama, clouds, seamless detail textures, sliced HUD icons) live under
`apps/client/public/art/` and are listed in `CREDITS.md`.
